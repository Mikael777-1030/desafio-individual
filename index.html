Impacto en la Comunidad Saludable

Esta herramienta proporciona a las postas médicas de zonas rurales o comunitarias un modelo computacional preciso para prever el margen de tiempo operativo seguro tras un fallo eléctrico. Permite tomar decisiones inmediatas como trasladar lotes de vacunas a termos de contingencia antes de alcanzar los 8°C.

Conclusión del Análisis Numérico

El método de **Runge-Kutta de 4.º Orden (RK4)** demuestra una concordancia prácticamente exacta con la solución analítica (errores menores a 0.001%), superando significativamente al **Método de Heun (RK2)**. Para simulaciones críticas de vida o conservación biológica, RK4 garantiza fiabilidad matemática aun con pasos de integración mayores.

Marco Teórico y Fundamentos

1. Modelo Físico - Ley de Enfriamiento de Newton

Establece que la tasa de cambio de temperatura de un cuerpo es proporcional a la diferencia entre su temperatura y la del medio ambiente:

dT/dt = -k(T - Tₘ)

2. Método de Heun (Runge-Kutta de Orden 2)

Es un esquema predictor-corrector que calcula la pendiente al inicio y final del intervalo:

  • k₁ = f(tᵢ, Tᵢ)
  • k₂ = f(tᵢ + h, Tᵢ + h·k₁)
  • Tᵢ₊₁ = Tᵢ + (h/2)·(k₁ + k₂)

3. Runge-Kutta de 4.º Orden (RK4)

Utiliza cuatro evaluaciones interlineales para lograr un orden de error truncamiento local de O(h⁵):

  • k₁ = f(tᵢ, Tᵢ)
  • k₂ = f(tᵢ + h/2, Tᵢ + h·k₁/2)
  • k₃ = f(tᵢ + h/2, Tᵢ + h·k₂/2)
  • k₄ = f(tᵢ + h, Tᵢ + h·k₃)
  • Tᵢ₊₁ = Tᵢ + (h/6)·(k₁ + 2k₂ + 2k₃ + k₄)
